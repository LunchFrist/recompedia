Recompedia is an index for players asking two practical questions: **does a recompilation or decompilation project exist for this game, and what does it take to run it?** The English-language site tracks 71 console games and 83 public project entries across PlayStation 2, Nintendo 64, GameCube and Xbox 360, including projects that run natively on PC or in a browser.

Each game page brings together project status, supported platforms, required game version, hardware notes, setup guidance, known issues and links to the project maintainers. Status labels distinguish `Playable`, `In Progress`, `Announced` and `Unknown`; a playable build is not assumed to be a finished game unless its project says so.

## How it works

- **Recompilation** translates a console executable into native code ahead of time. The resulting program runs on a desktop operating system or, for some projects, in a browser.
- **Decompilation** reconstructs readable source code from the original executable, usually aiming to compile back into an exact console build. A separate source-port project may use that work to make a native PC version.
- Project status, versions and requirements are checked against each project's own README, releases and repository metadata. Game descriptions and images are supplemented from [LizardByte GameDB](https://github.com/LizardByte/GameDB), a static mirror of IGDB; game pages credit the source.
- This public repository contains the project overview and change log, not the website source code or deployment configuration.
